GET

Read Data

📥

Apa itu HTTP GET?

Method untuk mengambil/membaca data dari server tanpa mengubah data.

  • Tidak mengubah data di server
  • Parameter dikirim via URL
  • Tidak memerlukan request body
📍 Endpoints
GET /kelas - Semua data
GET /kelas/{id} - Data spesifik

🔧 Langkah-langkah:

1

Pilih method GET dan masukkan URL

2

Tab Headers: tambahkan X-API-KEY: 123456

3

Klik Send

POST

Create Data

📤

Apa itu HTTP POST?

Method untuk mengirim data ke server dan membuat resource baru.

  • Data dikirim dalam request body
  • Membuat data baru di database
  • Response berisi ID data baru
📍 Endpoint
POST /kelas

🔧 Langkah-langkah:

1

Pilih method POST dan masukkan URL

2

Tab Headers: tambahkan X-API-KEY: 123456

3

Tab Body → pilih raw dan JSON

{
  "nama_kelas": "RPL 2",
  "tingkat": "XI"
}
4

Klik Send

📸 Screenshot POST Request
✅ Response (201 Created)
{
  "id": 67,
  "message": "Kelas berhasil dibuat"
}
PUT

Update Data

✏️

Apa itu HTTP PUT?

Method untuk mengupdate/memodifikasi data yang sudah ada di server.

  • Memerlukan ID data yang akan diupdate
  • Data baru dikirim dalam request body
  • Mengganti data lama dengan data baru
📍 Endpoint
PUT /kelas/{id}

🔧 Langkah-langkah:

1

Pilih method PUT dan masukkan URL dengan ID: /kelas/67

2

Tab Headers: tambahkan X-API-KEY: 123456

3

Tab Body → pilih raw dan JSON

{
  "nama_kelas": "RPL 2",
  "tingkat": "XI"
}
4

Klik Send

📸 Screenshot PUT Request
✅ Response (200 OK)
{
  "message": "Kelas berhasil diperbarui"
}
💡 Perbedaan POST vs PUT:
POST = Membuat data baru (tanpa ID)
PUT = Mengupdate data lama (perlu ID di URL)
DELETE

Delete Data

🗑️

Apa itu HTTP DELETE?

Method untuk menghapus data dari server secara permanen.

  • Memerlukan ID data yang akan dihapus
  • Tidak memerlukan request body
  • Data yang dihapus tidak bisa dikembalikan
📍 Endpoint
DELETE /kelas/{id}

🔧 Langkah-langkah:

1

Pilih method DELETE dan masukkan URL dengan ID: /kelas/51

2

Tab Headers: tambahkan X-API-KEY: 123456

3

Tidak perlu Body! Langsung klik Send

📸 Screenshot DELETE Request
✅ Response (200 OK)
{
  "message": "Kelas berhasil dihapus"
}
⚠️ Peringatan: Data yang dihapus tidak dapat dikembalikan! Pastikan ID sudah benar sebelum mengirim request.
Method Fungsi Endpoint Body Required Response Code
GET Mengambil data /kelas, /kelas/{id} ❌ Tidak 200 OK
POST Membuat data baru /kelas ✅ Ya (JSON) 201 Created
PUT Mengupdate data /kelas/{id} ✅ Ya (JSON) 200 OK
DELETE Menghapus data /kelas/{id} ❌ Tidak 200 OK

🎯 Best Practices

  • Selalu sertakan header X-API-KEY di setiap request
  • Gunakan format JSON yang valid untuk POST dan PUT
  • Perhatikan status code response (200, 201, 404, 500)
  • Save request dalam Collection untuk reusability
  • Test secara berurutan: GET → POST → GET → PUT → GET → DELETE
